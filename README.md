# 여기있짤 - 정적 웹앱 클론

원본 사이트의 확인 가능한 UI/기능을 참고해 새로 구현한 정적 이미지 보관 웹앱입니다.

## 실행

`index.html`을 브라우저에서 직접 열어도 되지만, 브라우저 보안 정책상 간단한 로컬 서버 사용을 권장합니다.

```bash
python -m http.server 8080
```

그 후 `http://localhost:8080` 접속.

## 기본 관리자 계정

- ID: `admin`
- PW: `admin1234`

관리자 로그인 후 **설정 → 관리자 계정 → 변경**에서 바꿀 수 있습니다.

## 구현 기능

- 이미지 다중 업로드 / 드래그 앤 드롭
- 이미지 이름, 메모, 태그, 폴더 수정
- 전체 / HOT(조회수순) / 폴더 / 즐겨찾기
- 이름·메모·태그 검색
- 폴더 생성 / 이름 변경 / 삭제
- 다중 선택 / 전체 선택 / 폴더 이동 / 즐겨찾기 / 삭제
- 선택 사진 ZIP 다운로드 (외부 라이브러리 없이 동작)
- 휴지통 / 복구 / 30일 자동 완전 삭제
- 사진 회전 / 단일 다운로드
- 통계 / 폴더별 사진 수 / 저장 용량
- 관리자 로그인 / 계정 변경
- 메타데이터 JSON 내보내기
- 반응형 모바일 UI

## 저장 방식과 주의점

사진은 서버가 아니라 **브라우저 IndexedDB**에 저장됩니다. 따라서 같은 사이트라도 PC와 휴대폰 간 데이터가 자동으로 공유되지 않습니다.

실제 서비스용으로 여러 기기에서 같은 사진을 보려면 Supabase, Firebase, AWS S3 + API 같은 백엔드를 연결해야 합니다. 또한 현재 관리자 로그인은 클라이언트 측 기능 제한용이므로 보안 인증 수단으로 사용할 수 없습니다.

## 배포

폴더 전체를 Netlify Drop, GitHub Pages, Cloudflare Pages 등에 그대로 올리면 정적 사이트로 동작합니다.
